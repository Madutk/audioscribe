# Testdaten für den Souffleur

Frei erfundenes Mini-Wiki (`wiki/`, Karpathy-Muster: `index.md`, `log.md`, `wiki/`, `raw/`)
und ein Mini-Transkript (`meeting/`) für die automatischen Tests. Keine echten Personen,
Firmen oder Prozesse. Das Wiki wird in den Tests über die Einstellung K1 (Wiki-Pfad)
angeschlossen, nicht über einen Sonderweg.

Das Transkript enthält absichtlich: zwei Widersprüche zum Wiki (Freigabegrenze,
Aufbewahrungsfrist), eine passende Aussage (Freigabefrist), eine echte Frage mit Antwort im
Wiki (Stammdatenpflege), eine echte Frage ohne Antwort im Wiki (Reisekosten), eine
rhetorische Frage, einen offenen Punkt (Schulung), einen verstümmelten Fachbegriff aus dem
Glossar („Fak Tura“) und Smalltalk.
