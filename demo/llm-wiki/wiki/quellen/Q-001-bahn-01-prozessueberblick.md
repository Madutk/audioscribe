# Q-001 · Prozessaufnahme 1: Prozessüberblick Bahnbuchung

## Beteiligte Rollen

- Moderator (nimmt den Prozess auf, keine Domänenrolle) [Q-001]
- [[ROL-001-assistenz|Assistenz]] (bucht die Bahnreisen für das Team) [Q-001]

## Zusammenfassung

Die Aufnahme beschreibt den Ablauf einer Bahnbuchung aus Sicht der Assistenz im Überblick. Jede Buchung beginnt mit einer Reiseanfrage per E-Mail an ein Teampostfach. Die Anfrage muss Reisedatum, Start, Ziel, späteste Ankunftszeit und BahnCard-Status enthalten; fehlende Angaben fragt die Assistenz per E-Mail nach. Gebucht wird im Browser auf bahn.de über ein Geschäftskundenkonto. Grundsätzlich wird zweite Klasse gebucht, erste Klasse nur bei Fahrten über vier Stunden, immer mit Sitzplatzreservierung. Das Ticket wird als PDF heruntergeladen und per E-Mail an die reisende Person geschickt. Das Volumen liegt bei etwa zehn Buchungen pro Woche, vor Messen deutlich mehr; eine Buchung dauert bei vollständiger Anfrage etwa zehn Minuten. Tarif und Bezahlung wurden auf die nächste Aufnahme vertagt.

## Kernaussagen

- Jede Bahnbuchung beginnt mit einer Reiseanfrage, die die Kollegen per E-Mail an das Teampostfach schicken. [Q-001 · 00:00:18]
- Pflichtangaben der Anfrage: Reisedatum, Start und Ziel, späteste Ankunftszeit, BahnCard ja/nein. [Q-001 · 00:00:34]
- Fehlt eine Angabe, fragt die Assistenz per E-Mail nach. [Q-001 · 00:00:34]
- Gebucht wird auf bahn.de im Browser. [Q-001 · 00:00:56]
- Die Anmeldung auf bahn.de erfolgt mit einem Geschäftskundenkonto. [Q-001 · 00:00:56]
- Grundsätzlich wird zweite Klasse gebucht. [Q-001 · 00:01:14]
- Erste Klasse gibt es erst, wenn die Fahrt länger als vier Stunden dauert. [Q-001 · 00:01:14]
- Es wird immer ein Sitzplatz reserviert; ohne Sitzplatzreservierung wird nichts gebucht. [Q-001 · 00:01:30]
- Nach der Buchung wird das Ticket als PDF heruntergeladen und per E-Mail an die reisende Person geschickt. [Q-001 · 00:01:42]
- Volumen: ungefähr zehn Buchungen pro Woche, vor Messen deutlich mehr. [Q-001 · 00:01:58]
- Dauer je Buchung bei vollständiger Anfrage: etwa zehn Minuten. [Q-001 · 00:02:12]
- Tarif und Bezahlung werden in der nächsten Aufnahme behandelt. [Q-001 · 00:02:20]
